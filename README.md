# TechShop
1.  Для чего нужен JavaScript? Чтобы задавать поведение страницы и делать её
    интерактивной, например реагировать на нажатия кнопок и менять содержимое
    без перезагрузки.

2.  Как подключить внешний файл script.js? С помощью тега <script
    src="script.js"></script>, обычно его ставят в самом конце body.

3.  Что такое DOM? Это представление HTML-страницы в виде объектов, с которыми
    JavaScript может работать, находить элементы и менять их текст или стили.

4.  Для чего нужен querySelector? Чтобы найти первый подходящий элемент на
    странице по CSS-селектору: по id, классу или тегу.

5.  Что такое событие click? Это событие, которое срабатывает, когда
    пользователь нажимает на элемент, например на кнопку.

6.  Что делает addEventListener? Вешает обработчик на элемент, то есть
    отслеживает нужное событие, например клик, и запускает указанную функцию,
    когда оно произойдёт.

7.  Зачем используется textContent? Чтобы получить или изменить обычный текст
    внутри HTML-элемента.

8.  Почему сообщение появляется только после нажатия? Потому что изначально
    абзац в HTML пустой, а команда, которая добавляет в него текст, находится
    внутри обработчика события click и выполняется только при клике.

9.  Чем отличаются селекторы #buy и .product? Селектор #buy выбирает элемент по
    его идентификатору id, а .product выбирает по классу class.

10. Что произойдёт, если указать несуществующий id? Метод querySelector ничего
    не найдёт и вернёт null. А при попытке повесить на него событие или поменять
    текст в консоли появится ошибка, и дальнейший код не выполнится.
